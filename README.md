# Escale

Appli de voyage de groupe : programme jour par jour, carte, réservations, liste de préparation et dépenses partagées (qui doit combien à qui).

- S'installe sur l'écran d'accueil du téléphone (appli web installable).
- Partage par lien d'invitation, sans compte à créer.
- Données synchronisées avec Firebase ; voir `GUIDE.md` pour la configuration.
